# BookMyFade

BookMyFade is a barber shop management and appointment booking application consisting of two parts:

- **Dashboard** – A management interface for administrators, shop owners, and barbers to manage appointments and their respective responsibilities.
- **Customer App** – A client-facing application that allows customers to browse available services and book appointments.

For more detailed information about the project, its functionality, and implementation, see the **`dokumentacija`** folder in the repository.
